# broker

completion-scoped credentials. an agent proposes an exact action, a human approves once, the credential works exactly once, and completion revokes the authority and keeps the evidence.

status: not built yet, and the spec comes first. work is tracked in the [`broker` issues](https://github.com/shashank-sn/warden.md/issues?q=label%3Atrack%3Abroker).

- downscoping exchange, one-use credential minting
- explicit completion with a ttl fallback
- policy: allow, require approval, block
